# Kampung Batik Giriloyo

Website landing page promosi untuk Kampung Batik Giriloyo di Desa Wisata Wukirsari, Yogyakarta.

Fokus utama website ini:

- Promosi batik tulis dan produk batik
- Informasi jasa belajar membatik
- Arah lokasi dan kontak cepat via WhatsApp
- Tampilan hangat, lokal, dan ramah pengunjung

## Fitur

- Hero section dengan CTA ke WhatsApp dan Google Maps
- Section produk batik
- Section belajar batik
- Informasi lokasi dan akses
- Galeri visual placeholder
- Form booking yang mengarahkan pesan ke WhatsApp
- Mobile-first dan responsif

## Tech Stack

- HTML
- CSS
- JavaScript

.

## Cara Menjalankan

Karena ini website statis, cukup buka `index.html` di browser.

Kalau mau pakai local server:

```bash
python3 -m http.server 4173
```

Lalu buka:

```text
http://localhost:4173
```

## Yang Perlu Diganti

Sebelum dipakai live, ganti bagian berikut dengan data asli:

- Nomor WhatsApp di `index.html` dan `main.js`
- Link Google Maps yang spesifik
- Foto atau galeri asli
- Copywriting bila mau disesuaikan dengan tone brand

## Catatan

- Website ini dibuat sebagai landing page satu halaman.
- Form booking saat ini membuka WhatsApp dengan pesan yang sudah terisi.
- Kalau nanti mau dikembangkan jadi Next.js, React, atau multi-page site, struktur kontennya sudah siap dipindah.
